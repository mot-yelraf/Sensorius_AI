# Weather glyphs

Eight original SVGs from Twemoji v17.0.2 by Twitter and other contributors:
https://github.com/jdecked/twemoji/tree/v17.0.2/assets/svg

Licensed under CC BY 4.0: https://creativecommons.org/licenses/by/4.0/
The full license is included in LICENSE-GRAPHICS.

Mapping: sunny=2600, partly-cloudy=1f324, cloudy=2601, rain=1f327,
snow=1f328, thunder=26c8, fog=1f32b, clear-night=1f319.

partly-cloudy-night.svg is a Sensorius adaptation combining the crescent
moon (1f319) and foreground cloud (2601), scaled and positioned together.
It is also distributed under CC BY 4.0. The other artwork is unmodified.
